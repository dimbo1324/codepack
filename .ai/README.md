# Модули правил для ИИ-ассистентов

Единственный источник правды для правил, которым подчиняются все ИИ-ассистенты
(Claude Code, Codex и любые будущие агенты) в этом репозитории.

## Как это устроено

```text
.ai/universal/*.md   Переносимые правила. Годятся для ЛЮБОГО проекта.
                     Не упоминают имён проекта, путей и особенностей стека.
.ai/project/*.md     Правила именно этого проекта: карта репозитория, команды,
                     доменные ограничения, трекинг прогресса, легаси-эталон.
CLAUDE.md            Тонкая точка входа для Claude Code. Импортирует все
                     модули нативным синтаксисом @path.
AGENTS.md            Точка входа для Codex. ГЕНЕРИРУЕТСЯ склейкой тех же
                     модулей (у Codex нет механизма импорта). Руками не править.
```

Модули загружаются в порядке имён: сначала `universal/01..NN`, затем `project/10..NN`.
Более позднее переопределяет более раннее — проектные правила сильнее универсальных
при конфликте (например, более строгий лимит размера файла).

## Как править правила

1. Отредактируйте или добавьте модуль в `.ai/universal/` или `.ai/project/`.
2. Пересоберите точку входа Codex: `python dev_tools_scripts_runner.py sync-agents`.
3. Закоммитьте модуль и пересобранный `AGENTS.md` вместе.

`AGENTS.md` править руками запрещено — у него баннер сгенерированного файла, и любая
ручная правка будет потеряна при следующей синхронизации. `CLAUDE.md` пересобирать не
нужно: Claude Code разрешает `@`-импорты в начале сессии.

## Бюджет размера и уровни модулей

Codex читает не более 32 KiB проектных инструкций; скрипт синхронизации падает, если
собранный `AGENTS.md` превысил 30 KiB. Русский текст в UTF-8 занимает около 2 байт на
символ, поэтому все модули целиком в этот бюджет не помещаются.

Решение — два уровня модулей:

- **inline** (по умолчанию) — модуль встраивается в `AGENTS.md` целиком.
- **extended** — модуль не встраивается; в `AGENTS.md` попадает только его заголовок,
  путь и однострочное резюме. Помечается маркером в первых строках файла:

  ```markdown
  <!-- tier: extended -->
  ```

  Такой модуль **обязан** содержать строку резюме сразу после заголовка:

  ```markdown
  > **Суть.** Одно предложение с главными правилами модуля.
  ```

Принцип разделения: **inline** — то, что нужно знать до чтения чего-либо ещё
(ориентация, процесс, ограничения, предотвращающие необратимый вред). **extended** —
уточнения, которые читаются, когда задача их касается.

Правила уровня `extended` действуют наравне с остальными: их пропуск — нарушение,
а не право выбора. `CLAUDE.md` импортирует **все** модули независимо от уровня,
поэтому Claude Code всегда видит полную детализацию.

## Перенос в другой проект

1. Скопируйте `.ai/universal/` без изменений.
2. Скопируйте `CLAUDE.md` и скрипт синхронизации.
3. Полностью перепишите `.ai/project/` под новый проект.
4. Запустите синхронизацию, чтобы получить новый `AGENTS.md`.

Держите универсальные модули действительно универсальными: если правилу нужен путь
или команда конкретного проекта — его место в `.ai/project/`.
