# Документация codepack

Индекс документов. Здесь живёт **состояние проекта** — то, что должно пережить потерю
любого чата и смену любой модели.

## Корневые документы (вне `docs/`)

| Файл | Отвечает на вопрос |
|---|---|
| `BLUEPRINT.md` | Что за продукт, как устроен, вся логика, форматы и математика |
| `ROADMAP.md` | Что строим, в каком порядке, что уже готово |
| `AGENTS.md` | Правила работы для ИИ-агентов (сгенерированный свод) |
| `CLAUDE.md` | Точка входа Claude Code |
| `task-checklist.md` | Текущая или последняя задача |

## Документы состояния

| Файл | Отвечает на вопрос |
|---|---|
| `architecture/overview.md` | Что **реально** построено в коде прямо сейчас |
| `architecture/invariants.md` | Что нельзя ломать никогда |
| `decisions/open-questions.md` | Решения владельца и открытые вопросы |

## Архив

| Путь | Содержимое |
|---|---|
| `__arch__/codepack-main.zip` | Старая реализация на Python (эталон поведения) |

Правила обращения к архиву — в `.ai/project/14-legacy-reference.md` и в скилле
`legacy-lookup`. Распаковывать только во временный каталог вне репозитория.

## Правило актуальности

Если план, документ состояния и код противоречат друг другу — **код является фактом,
план является намерением**. Расхождение устраняется в той же задаче либо явно
сообщается. Устаревшая документация хуже её отсутствия.
